## SECTION 2 — LOCAL AI INTERFACE: LM STUDIO

### What It Is (ESTABLISHED — demonstrated)
LM Studio (lmstudio.ai) — free desktop app. Downloads and runs AI models locally. Alternative to Ollama with a GUI.

**Advantages over raw Ollama:**
- Hardware compatibility check built-in — tells you if a model is "likely too large to run" before downloading
- Visual model browser — see size, capability, quantization level
- Chat interface like ChatGPT — private conversations with PDFs, images
- Web search via Brave integration
- 3-step plug-in to Claude Code / Open WebUI / other tools

**Critical finding for CyberPower tower:**
> "Gemma 2B and 4B were built to work on your mobile phone. If you've got a really old computer, most likely you'll be able to download at least this model."

GTX 1050 2GB VRAM = Gemma 2B on GPU. LM Studio confirms this is viable even on old hardware.

### Install Sequence for Tower
```
1. lmstudio.ai → download Windows installer
2. Install Node.js (needed to run JavaScript-powered integrations)
3. Open LM Studio → Settings → Hardware → verify what it detects
4. Browse models → Gemma 2B E (confirmed mobile-grade, runs on any hardware)
5. Download + load model
6. Plug into Claude Code: LM Studio serves on local port → Claude Code points to it
```

**LM Studio vs Ollama decision:**
- LM Studio: better for model discovery, hardware safety checks, privacy-sensitive chat
- Ollama: better for headless server mode (no GUI), API-first, always-on background service
- **Tower should run both:** Ollama as the API server (headless, always-on), LM Studio for model testing + exploration

## SECTION 3 — MONETIZATION DOCTRINE: STOP LEARNING, START SELLING

### The Core Insight (ESTABLISHED — personal testimony + demonstrated outcomes)
> "You will never feel ready. Never. That feeling of readiness comes from the other side of that awkward first sales call."

The learning loop trap: discover AI → take courses → build demos for nobody → feel productive → bank account unchanged. The break: **sell before you're ready**.

### What Business Owners Buy
> "They don't buy AI. They buy a fixed problem."

Frame shift: you are not selling Claude Code. You are selling:
- Hours saved
- Money saved
- Extra revenue generated
- Avoiding a new hire

Same exact build — different framing = $50/hour vs $5,000/project.

### The 3-Step Activation Protocol

**Step 1 — Pick ONE business type** (commit 30 days minimum)
Target: high lifetime customer value businesses
- HVAC / plumbing: $3K–10K per job
- Dentist: thousands per patient over lifetime
- Med spa: hundreds per visit, recurring

Specialization = steakhouse pricing vs buffet pricing. After 10 conversations with the same niche you sound like a decade-long specialist.

**Step 2 — Pick ONE problem**

| Problem | Solution | ROI pitch |
|---|---|---|
| Missed calls | AI voice agent (24/7 call answering) | Lost leads = lost revenue. Agent pays for itself with 1 recovered job |
| Slow follow-up | Automated follow-up system | Leads followed up in seconds vs hours = conversion spike |
| Dormant database | Reactivation campaign | Five figures in a week from past customers who "went cold" |

**Step 3 — Send 10 messages today**

Outreach template:
```
"Hey, I work with [niche] to help them solve [specific problem].
I noticed [specific observation about their business].
I've built systems that fix that and businesses I've worked with
are seeing [specific result].
Would you be open to a quick 15 minutes this week to see if
this would make sense for you?"
```

No pitch deck. No funnel. No 47-step process.

**On the call — frame in time + money:**
```
"You're spending 5 hours/week following up leads manually.
At $100/hour that's $2,000/month, $24,000/year.
My system wipes that out. Setup costs $2,000.
By month two, it's paid for itself."
```
