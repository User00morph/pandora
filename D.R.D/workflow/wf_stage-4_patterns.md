## PART A — PATTERN RECOGNITION

With all evidence extracted, step back and look at the whole picture.

**Answer these five questions:**

**1. WHERE IS THERE GENUINE CONSENSUS?**
Multiple Tier 1–2 sources pointing the same direction = high confidence finding.

**2. WHERE IS THERE GENUINE DISAGREEMENT?**
Tier 1–2 sources contradicting each other = document the disagreement honestly. Do not pick a side without examining why the disagreement exists.

**3. WHERE IS THE EVIDENCE THIN?**
Only Tier 3–4 sources available = finding is possible, not established.

**4. WHERE IS THE EVIDENCE ABSENT?**
Widely claimed but no traceable primary source = Tier 5. Flag as assertion, not finding.

**5. WHAT IS THE STRONGEST CASE AGAINST?**
Even if a conclusion seems clear — articulate the strongest version of the opposing evidence. If the opposing case cannot be articulated, the research is incomplete.

**Output:** Pattern summary organized by confidence level:
`ESTABLISHED / PROBABLE / POSSIBLE / CONTESTED / NEEDS EVIDENCE`

> Note on NEEDS EVIDENCE: not dismissed — flagged as requiring more sourcing. Include what specific evidence would strengthen or resolve the claim.

## PART B — CONCEPT DISTILLATION

**Load: `shared/skills/skill_concept-distillation.md`**

Before building the sovereign position, distill the core concepts that emerged from pattern recognition. Reconstruction is built on clearly understood foundations — not half-absorbed complexity.

For each key concept identified in Part A:

1. **EXTRACT THE ROOT** — one sentence, no jargon
2. **IDENTIFY THE PILLARS** — 3–5 load-bearing elements
3. **MAP THE RELATIONSHIPS** — how pillars connect to each other
4. **BUILD THE LAYERS:**
   - Layer 1 (The Seed): 1–3 sentences, zero background needed
   - Layer 2 (The Scaffold): ~1 page, terms defined inline
   - Layer 3 (The Full Architecture): complete with nuance and edge cases
5. **DISTORTION CHECK** — does Layer 1 still carry Layer 3's truth?

**Output:** Concept distillation(s) embedded in or appended to the decoded file in `deconstructions/[domain]/`. These distillations feed directly into Stage 5.

## PART C — GAME THEORY OVERLAY
**Load for any topic in the systemic-analysis domain. Optional for all others.**
*Source framework: Professor Jiang — Secret History + GT#7 | Decoded in `drd_decode_jiang-secret-history_decoded.md` + `drd_decode_jiang-game-theory-7-americas-game_v1.md`*

After completing Parts A and B, if the topic involves power, control, institutions, economics, history, or any system with multiple actors — run the Game Theory Overlay before moving to Stage 5.

This layer surfaces hidden game structure that pattern recognition alone misses.

---

### MOVE 1 — STATED GAME vs. ACTUAL GAME

```
STATED GAME:   What does the system say it is doing? (official narrative, public mission, stated purpose)
ACTUAL GAME:   What is it structurally producing? (follow the resource flow, not the stated intent)
```

The stated game is always presented in terms of benefit to participants.
The actual game is revealed by asking: who receives the extracted value at the end of every cycle?

---

### MOVE 2 — PLAYER / OPERATOR DISTINCTION

```
PLAYERS:   Who believes they are competing within the game?
           (They follow the rules. They pursue the stated objective. They believe the game is theirs.)

OPERATOR:  Who designed the board, sets the rules, and determines what winning means?
           (They do not compete. They harvest the competition. They are usually invisible within the game's frame.)
```

Key tells: the operator is not identifiable from inside the game.
The operator shapes the environment that all players believe is neutral.

---

### MOVE 3 — EXTRACTION HIERARCHY

Map every actor to their position in the value chain:

```
TIER 1 — FINANCE:       Creates value from value. Highest margin. Controls what wealth means.
TIER 2 — KNOWLEDGE:     Owns IP, patents, information. Sells the map, not the territory.
TIER 3 — MANUFACTURING: Converts resources into goods. Margin set by Tier 1 pricing.
TIER 4 — RESOURCES:     Generates the actual physical energy. Lowest margin. Funds everything above.
```

Questions:
- Where does this topic sit in the hierarchy?
- Who is being paid at resource-tier rates for finance-tier work?
- What would change if a lower tier refused to play at its assigned price?

---

### MOVE 4 — COORDINATION MECHANISM

```
What holds the controlling group together?
```

Options (not mutually exclusive):
- **Transgression cohesion** — shared crime eliminates the defection incentive; mutual compromise = permanent bond
- **Ideological capture** — shared worldview (inverted or otherwise) that frames extraction as virtue
- **Institutional inertia** — no active coordination needed; the structure selects for compatible actors
- **Financial dependency** — supply dependency ensures loyalty without requiring belief

Identifying the coordination mechanism tells you what would actually break the system.
Attacking the ideology when the mechanism is transgression cohesion changes nothing.

---

### MOVE 5 — CYCLE PHASE

Every system operating on a narcissistic architecture runs the same cycle:

```
IDEALIZE:  Offer protection, civilization, opportunity, salvation
           → Recruit participants voluntarily; create genuine initial value
           → Players believe the game is theirs

DEVALUE:   Extract resources, impose debt, criminalize independence
           → Rules shift to favor the operator; players face increasing friction
           → The stated game no longer functions as advertised

DISCARD:   Abandon depleted populations, collapsed systems, exhausted territories
           → Move to next source of supply
           → Old players reframe as the problem (DARVO: the abandoned are blamed for the collapse)

RESET:     New idealize phase begins under different branding
           → Same architecture, new myth
```

Identify current phase: Where is this system in the cycle right now?
Phase determines strategy — you engage an idealize phase differently than a discard phase.

---

### MOVE 6 — THREE STRUCTURAL LIMITATIONS

Every system has constraints that eventually break it. Jiang's method: identify the three load-bearing walls.

```
CONSTRAINT 1: [What physical, biological, or material limit caps the system's reach?]
CONSTRAINT 2: [What ideological or legitimacy limit caps its recruitment?]
CONSTRAINT 3: [What coordination or communication limit caps its coherence?]
```

Then ask: How is the system currently trying to overcome each constraint?
The attempt to overcome constraints is where the next phase of the game is built.

---

### MOVE 7 — GAME RESET SIGNALS

A game reset is when the organizing principle of the system begins to fracture:

```
Signal 1: A lower-tier actor successfully asserts power upward (resource tier threatening finance tier)
Signal 2: The legitimating mythology loses credibility at scale (players no longer believe the stated game)
Signal 3: Alternative coordination systems emerge outside the game's architecture
Signal 4: Internal elite faction warfare becomes visible (supply competition breaks into the open)
```

If any signals are present in the topic being researched — note them. A game reset is both the highest-risk and highest-opportunity window. Old pattern recognition no longer applies. Stage 5 reconstruction must account for which phase of reset is active.
