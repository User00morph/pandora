# SKILL — WEEKLY PREP PROTOCOL
**Sunday Pre-Week Preparation Sequence**
**Load when:** Every Sunday before the trading week begins.
**Department:** D.S.E trading workspace | STIS Weekly Layer | Week planning

---

## WHAT THIS IS

Sunday prep sets the context for the entire week. Done properly, every morning session takes 10 minutes instead of 30 because the weekly framework is already built.

---

## THE SUNDAY SEQUENCE (60-90 minutes)

### BLOCK 1 — UPDATE LIVE INTELLIGENCE (20 min)

```
1. CHECK MACRO (Layer 3):
   □ DXY — where is it relative to last week? Trend change?
   □ 10Y / 30Y yields — continuation or reversal?
   □ Gold, Oil — any structural developments?
   □ COT report released Friday → update currency positioning read
   □ Any major economic events this week? (CPI, FOMC, NFP)
   → Log: update dse_intelligence_current-field.md if materially changed

2. M2 MONEY SUPPLY (check monthly):
   □ Is global liquidity expanding or contracting?
   → One line: "M2: [expanding/contracting/flat] → risk [on/off/neutral]"
```

---

### BLOCK 2 — ESOTERIC CONTEXT (15 min)

```
3. RUN WEEKLY ASTRO PREP (Layer 4):
   □ Run skill_weekly-astro-prep-protocol.md
   □ Identify: which days look favorable, which look volatile/chaotic
   □ Note any major transits this week
   → Log: 5-day grid of planetary themes

4. MARKOV STATE — WEEKLY HORIZON (10 min):
   □ Run Markov on primary instruments (EUR/USD, Gold, NQ/SPY proxy)
   □ Square the matrix for a 3-day forward view
   □ Note the weekly bias from the statistical layer
   → Log: "Markov weekly: [Bull/Bear/Sideways] | 3-day signal: [+/-X%]"
```

---

### BLOCK 3 — LEVEL STACK BUILD (20 min)

```
5. BUILD THE WEEKLY LEVEL MAP:
   □ Mark previous week's high, low, open, close on all instruments
   □ Run GEX engine for the week (note weekly gamma wall and call/put walls)
   □ Identify any power clusters for the week (GEX + volume + auto key levels)
   □ Note the current IEC phase for primary instrument

6. IDENTIFY HIGH-PROBABILITY WINDOWS:
   □ Economic events calendar → flag high-volatility days
   □ Markov high-signal days → flag for full-size readiness
   □ Esoteric favorable days → flag as quality session candidates
   → Output: "Best days this week: [days] | Reduce/avoid: [days]"
```

---

### BLOCK 4 — RISK BUDGET (10 min)

```
7. SET WEEKLY RISK BUDGET:
   □ What is the current account equity?
   □ Weekly maximum risk = 5% of equity
   □ Daily maximum risk = weekly budget / 5
   □ If last week ended with a loss: reduce weekly budget by 20%

8. POSITION SIZING TABLE:
   □ At daily risk budget, what is maximum position size?
   □ For each instrument: stop distance × dollar per point = max contracts
   → Log: "Week budget: $[X] | Daily max: $[X] | Max contracts: [table]"
```

---

## WEEKLY LOG OUTPUT

```
WEEK OF: [YYYY-MM-DD]
MACRO CONTEXT: [one paragraph — M2, yields, DXY, major events]
ESOTERIC CONTEXT: [dominant Ray, key planetary events, best/avoid days]
MARKOV BIAS: [state + 3-day signal for each instrument]
POWER CLUSTERS: [list of high-confluence levels with prices]
HIGH-PROB WINDOWS: [days and sessions]
WEEKLY RISK BUDGET: $[X] | DAILY MAX: $[X]
HYPOTHESES: [1-3 high-probability setups to watch for this week]
```
