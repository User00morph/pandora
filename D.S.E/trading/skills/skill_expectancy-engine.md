# SKILL — EXPECTANCY ENGINE
**The Statistical Foundation of Any Trading System**
**Load when:** Evaluating a new strategy, reviewing system performance, or questioning whether to keep trading a system.
**Department:** D.S.E trading workspace | STIS System Evaluation Layer

---

## WHAT THIS IS

The single mathematical question that determines whether a trading system is worth running: does it have positive expectancy? Everything else — psychology, discipline, execution — is secondary to this number.

---

## THE FORMULA

```
EXPECTANCY = Win Rate × Average Win − Loss Rate × Average Loss

Simplified: Win Rate × Risk:Reward Ratio = Expectancy per unit risked

Example:
  Win rate:       45%
  Risk:Reward:    2.2:1
  Expectancy:     0.45 × 2.2 − 0.55 × 1 = 0.99 − 0.55 = +0.44R per trade

  This system makes 0.44R on average per trade taken.
  At 1% risk per trade → 0.44% expected gain per trade.
```

---

## WHAT POSITIVE EXPECTANCY MEANS FOR EXECUTION

When expectancy is confirmed positive:
- **Every signal must be taken** — skipping signals is statistically destroying your edge
- **Psychology is not the variable** — the math works whether you feel good or bad
- **Individual trade outcomes are irrelevant** — only the distribution matters over sample size

"If psychology is becoming a big part of it, it's probably gambling in disguise."

---

## THE EVALUATION CHECKLIST

Before running any system live, confirm:

```
□ Win rate calculated over 100+ trade sample (not 10)
□ Average win and average loss calculated (not assumed)
□ Expectancy is positive across 3+ market conditions
□ Expectancy holds on walk-forward test (not just in-sample)
□ System has been run on 2+ uncorrelated assets
```

If all five pass → the system has earned real capital.

---

## THE BENCHMARKS

| Expectancy | Assessment |
|---|---|
| Negative | System loses money over time — do not run |
| 0 to +0.1R | Marginally positive — fees may erase edge |
| +0.1R to +0.3R | Viable — run with standard sizing |
| +0.3R to +0.5R | Strong — run with full sizing |
| Above +0.5R | Elite — scale capital aggressively |

---

## THE PERIOD DISTRIBUTION CONTEXT

Positive expectancy manifests differently at different timeframes:

```
DAILY level:     48% winning days — looks like noise, nearly random
WEEKLY level:    54% winning — barely above chance
MONTHLY level:   56% winning — edge becoming visible
YEARLY level:    70-77% winning — clear systematic edge
DECADE level:    100% winning — structural, regime-independent edge
```

A 48% daily win rate with positive expectancy is NOT a failing system — it is a correctly functioning trend-following system. The edge accumulates at the year and decade level, not the day level. Evaluate the system at the YEARLY timeframe minimum.

---

## RULES

- Calculate expectancy BEFORE running any system with real capital
- A system that loses more than half its trades can have positive expectancy — the math determines viability, not win rate alone
- Recheck expectancy every 50 trades — edges degrade
- Daily win rate below 50% is normal and expected for trend-following systems
