# SKILL — FOUR FORCES DOMINANCE READ
**Pre-Session Dominant Force Diagnostic**
**Load when:** Every morning after Vanna check, before GEX regime read, before touching any chart.
**Department:** D.S.E trading workspace | STIS Layer 1b | Daily context setter

---

## WHAT THIS IS

Before any chart is opened, one question determines the entire session posture: **which of the four mechanical forces is dominant today?** This framework replaces "what does the chart look like" with "what force is running the market today."

---

## THE FOUR FORCES

| Force | What it tells you | Where to read it |
|---|---|---|
| **Delta** | Which direction dealers are hedging RIGHT NOW | Live options flow / GEX output |
| **Gamma** | Will the move be PINNED or ACCELERATED | Price vs. HVL from GEX engine |
| **Vanna** | What mechanical direction does VIX create | 5-day VIX trend (check first) |
| **Charm** | What is the afternoon gravity target | Nearest GEX level to yesterday's close |

---

## THE DAILY DOMINANT FORCE QUESTION

Ask this before any chart opens:

```
1. What is VIX doing? → Vanna direction (long tailwind / short headwind / neutral)
2. Where is price vs. HVL? → Gamma regime (mean-reverting / trending)
3. Which way are dealers hedging? → Delta direction (net long / net short / mixed)
4. What is the afternoon gravity target? → Charm level (nearest GEX wall)

DOMINANT FORCE TODAY = the one with the strongest signal
```

---

## DOMINANCE HIERARCHY

When forces conflict, this hierarchy resolves:

```
1. VANNA — if VIX is moving more than 1pt, Vanna overrides Gamma
2. GAMMA — if VIX is flat, Gamma regime sets the behavioral template
3. DELTA — intraday directional lean within whatever regime Gamma defines
4. CHARM — afternoon only, becomes dominant in final 2 hours
```

---

## SESSION POSTURE OUTPUT

After running the four forces diagnostic, produce one line:

```
─────────────────────────────────────
DOMINANT FORCE: [Gamma / Vanna / Charm / Mixed]
SESSION POSTURE: [fade / follow / observe / wait]
MECHANICAL BIAS: [long / short / neutral]
─────────────────────────────────────
```

**This framework is not about entries. It gives you context.** Context is what separates consistently profitable sessions from reactive ones.

---

## RULES

- Run this AFTER Vanna check, BEFORE GEX regime read
- Never skip — even on "obvious" days the dominant force check prevents surprises
- "Mixed" is a valid output — it means reduce size and wait for clarity
