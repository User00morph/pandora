# SKILL — WEEKLY REVIEW PROTOCOL
**End-of-Week System and Performance Review**
**Load when:** Every Friday after market close or Saturday morning.
**Department:** D.S.E trading workspace | STIS Weekly Layer | Performance refinement

---

## WHAT THIS IS

The weekly review is how the STIS improves. Without structured review, the same errors repeat indefinitely. With it, every week produces one concrete improvement to the system.

---

## THE FRIDAY/SATURDAY SEQUENCE (45-60 minutes)

### BLOCK 1 — TRADE REVIEW (20 min)

```
For every trade taken this week:

1. REVIEW THE ENTRY:
   □ Was the pre-trade checklist fully passed? (12/12)
   □ Was the session grade appropriate (A or A+)?
   □ Did I enter at a genuine key level or mid-range?
   Grade: A (followed protocol) / B (minor deviation) / F (broke rules)

2. REVIEW THE MANAGEMENT:
   □ Did I follow the position management protocol stages?
   □ Did I widen any stops? (if yes → F grade, investigate why)
   □ Did I take profits too early? Why?
   Grade: A / B / F

3. REVIEW THE EXIT:
   □ Did I exit at the planned target or thesis invalidation?
   □ Did I overstay or exit early without a protocol reason?
   Grade: A / B / F

4. R-MULTIPLE SUMMARY:
   □ Total R earned this week: [+X.XX R]
   □ Average R per trade: [+X.XX R]
   □ Win rate: [X/X trades = X%]
```

---

### BLOCK 2 — HYPOTHESIS REVIEW (10 min)

```
From the weekly prep, I identified [N] hypotheses. Review each:

HYPOTHESIS 1: "[The stated hypothesis]"
  Outcome: Confirmed / Disconfirmed / Inconclusive
  Why: [brief explanation of what actually happened]
  Learning: [what this tells me about this setup type]

→ This builds a personal playbook of what works and doesn't
```

---

### BLOCK 3 — SYSTEM CHECK (10 min)

```
□ Is the STIS performing within the expected backtest distribution?
   Expected weekly win rate: 54%
   This week's win rate: [X%]
   Within range? YES / NO (if NO for 3 weeks → run robustness check)

□ Are any skills being misapplied?
   Review the pre-trade checklists from this week
   Were any layers misread? Which ones?

□ Is there a pattern to the losses?
   Same session? Same instrument? Same regime type?
   → Log the pattern → becomes a rule refinement next week
```

---

### BLOCK 4 — ONE IMPROVEMENT (5 min)

Every week produces exactly ONE concrete improvement to the STIS:
```
THIS WEEK'S IMPROVEMENT:
  Problem identified: [specific issue from the review]
  Skill to update: [which skill file needs updating]
  Change: [exactly what to change]
  → Make the change NOW before closing the review
```
