# SKILL — PYRAMIDING PROTOCOL
**Adding to Winners Using Unrealized Profit as Capital**
**Load when:** A position is in profit and a new structural high or breakout signal fires.
**Department:** D.S.E trading workspace | STIS Position Management

---

## WHAT THIS IS

Pyramiding = adding to winning positions using the position's own floating profit as margin. No new capital deposited. The original position funds all additions. This is how 530%+ annual returns are possible from a single starting position.

---

## THE SEQUENCE

```
CONTRACT 1: Open at original signal
  → Price moves to new structural high
  → Floating profit now exceeds cost of Contract 2

CONTRACT 2: Add using floating profit (no new capital)
  → Price continues to new structural high
  → Combined floating profit exceeds cost of Contract 3

CONTRACT 3: Add again using floating profit
  → Stop loss advances to protect all three positions
  → Average entry is now far below current price

CONTRACT N: Continue until stop loss is hit
  → The stop governs exit — not a take profit
```

"Thirty minutes of work over two years." Starting with $5k → multi-contract position funded entirely from the trade's own profits.

---

## THE ADVANCEMENT RULE

Stop loss advances ONLY when a new signal fires (new structural high):
- Stop does NOT trail continuously
- Stop stays fixed until a new breakout confirms the trend
- Then ALL existing stop losses advance together to protect the full pyramid

This protects profits without triggering premature exits on normal retracements.

---

## THE MATH CHECK (run before each addition)

```
New contract cost = Margin + (Stop distance × Dollar per point)
Floating profit available = Current P&L (unrealized)

Can add IF: Floating profit ≥ New contract cost
Cannot add IF: Floating profit < New contract cost
```

---

## WHAT NOT TO DO

**Doubling down** = adding to LOSERS → account destruction. The opposite of pyramiding.

Pyramiding adds to WINNERS only, funded by THEIR OWN profit. The distinction is absolute.

---

## RULES

- Never add to a losing position — pyramiding is winners only
- Calculate the full position cost before adding (margin + stop distance cost)
- Advance the stop on ALL contracts when a new add signal fires
- The stop loss is the only exit mechanism — no take profit on the pyramid
