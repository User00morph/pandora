## WHAT THIS SKILL DOES
Read a chart, identify the active support/resistance levels and KimG/Nawaf setup criteria per `frameworks/trd_framework_support-resistance-system_v1.md` §1–2, and state whether current price action confirms a tradeable A+ setup:

1. Establish HTF structural bias and this week's range edges (Layer 1–2).
2. Check for a power cluster / unmitigated zone at the level price is testing (Layer 4–5, KimG structure).
3. Run the Nawaf 5-step timing checklist out loud — HTF baseline touch, LTF baseline touch, body close, EMA stack, wick-flip trigger. Any unticked step (or unverifiable without a live screenshot) = grade ❓, not A+.
4. If every step ticks: state entry, stop, and target sized per `_config/trd_config_tiki-profile.md`, then hand off to Stage 2's confirmation step before any live action.
5. If any step fails or is unverifiable: state clearly that it is not A+ — no trade, no partial credit.
